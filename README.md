# СРМ: прототип сценария покупки

Кликабельный HTML-прототип редизайна «Свободного Рынка Миниатюр»: покупка гостем от главной до письма о заказе.

Это концепт для обсуждения, а не рабочий сайт. Заказы не создаются, введённые данные никуда не отправляются. Фото и описания лотов взяты с [minifreemarket.com](https://minifreemarket.com/) для наглядности.

- `index.html`: панель проверки с ширинами экрана, состояниями и отличиями от текущего сайта
- `app.html`: сам прототип без панели
